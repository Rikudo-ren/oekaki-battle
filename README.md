# おえかきバトル！

友だちと同じ部屋に集まり、順番に絵を描いて当てるオンラインゲームです。2〜8人で遊べます。ホストが1〜5周を選んで開始すると、描く順番がランダムに決まります。描く人だけにお題が表示され、ほかの人には文字数が表示されます。ひらがな（長音「ー」を含む）で最初に正解した人に1ポイント。正解後はホストが次のターンへ進めます。

## Firebase の無料プランで始める

Firebase Hosting、Authentication（匿名認証）、Realtime Database を使います。**Cloud Functions は使わないので、Spark（無料）プランで始められます。** 各サービスには無料枠と利用上限があり、無制限ではありません。利用状況は Firebase コンソールで確認してください。無料枠を超えた場合はサービスが制限されることがあります。

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作成（または既存プロジェクトを選択）し、料金プランが Spark であることを確認します。
2. 「Authentication」→「Sign-in method」で **匿名** を有効にします。
3. 「Realtime Database」でデータベースを作成します。リージョンを選び、最初はロックモードで作成してください。後のデプロイでこのリポジトリのルールが適用されます。
4. プロジェクト設定の「マイアプリ」でウェブアプリを登録し、表示された Firebase 設定を `public/firebase-config.js` に記入します。Realtime Database の画面に表示される URL を `databaseURL` に指定してください（ウェブアプリの設定に含まれない場合があります）。これらはクライアント用の設定であり、アクセス制御はデータベースルールで行います。サービスアカウントの秘密鍵は入れないでください。
5. Firebase CLI を使ってログインし、デプロイ先を選択します。既存の `.firebaserc` は別プロジェクトを指している場合があるので、**必ず自分のプロジェクト ID を指定**してください。

```sh
npm install
npm run build
npx firebase-tools login
npx firebase-tools use --add
npx firebase-tools deploy --only database,hosting
```

デプロイ後、Hosting の URL を友だちに共有してください。Hosting 以外の独自ドメインで公開する場合は、Authentication の承認済みドメインに追加してください。別の参加者は別のブラウザまたはプライベートウィンドウを使用してください（匿名認証の ID はブラウザ内で共有されます）。

## 開発・動作確認

Node.js 22 を使用してください。`npm run build` で `src/app.js` を `public/app.js` にバンドルします。ローカルの静的サーバーで見た目を確認できますが、オンライン機能には上記の Firebase 設定とデプロイ済みデータベースルールが必要です。ローカルのドメインが認証の承認済みドメインに含まれているかも確認してください。

```sh
npm install
npm run build
npx serve public
```

## 仕組みと運用上の注意

- お題は Realtime Database の `secrets` に保存し、現在描いている人以外が直接読み取れないようルールで制限します。正解の書き込みはルールが判定し、トランザクションで最初の1人だけを記録します。得点は正解記録から集計します。
- サーバーを使わない友だち同士のカジュアルなゲーム向けです。ホストのブラウザがお題を生成しゲーム進行を管理するため、ホストは開発者ツールなどでお題や進行を操作でき、厳密な不正防止はできません。また、認証済みユーザーは合言葉を知っていれば部屋情報を読み取れます。公開サービスには追加の対策が必要です。8人制限は参加時の画面側の確認で、同時参加時には超過する可能性があります。
- 待機中にホストが退出した場合は、残った参加者にホストが移ります。ゲーム中にホームへ戻っても参加情報は残り、同じブラウザで同じ合言葉から再参加できます。プレイ中の自動退出、タイムアウト、お題のスキップ、部屋や描画データの自動削除はありません。ホストが準備中に通信を失うなど進行不能になった場合は新しい部屋を作成してください。不要なデータは Firebase コンソールで削除してください。
- 以前の Cloud Functions 版をすでにデプロイした場合、この変更では既存 Functions は自動削除されません。Firebase コンソールで不要な関数を確認・削除してください。
